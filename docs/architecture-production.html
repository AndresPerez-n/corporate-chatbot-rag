Key production deltas vs. the prototype: event-driven ingestion · metadata-aware vector store enabling JWT-based access control at the retrieval layer · hybrid retrieval + cross-encoder re-rank · model tiering + semantic cache for cost · Phoenix tracing + RAGAS eval harness driving the observe → evaluate → experiment flywheel.
