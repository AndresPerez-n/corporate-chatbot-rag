Clients Gateway / Auth Ingestion Retrieval + Generation Stores Observability / Eval / Experimentation
Production deltas vs. the prototype: event-driven ingestion · metadata-aware vector store enabling JWT access control at the retrieval layer · hybrid retrieval + cross-encoder re-rank · model tiering + semantic cache · LLM-observability tracing · a QA regression suite (predetermined Q&A) gating deploys · a production metrics DB for live performance + feedback · and A/B experiments to select the best variant.

Rollout: start with a pilot of 10 representative employees (across HR, Eng, Product) before real operations, then A/B between variants, then graduated rollout to all staff.
